# 결정 이력 (왜 이렇게 했나)

시간순. 날짜는 모두 2026-11-03 세션 기준.

1. **허브 방식 선택**: 매니페스트(`apps.json`) 기반 허브. 앱 추가/삭제는 목록 한 줄. 앱은 서로 독립(의존 없음).
2. **배포**: GitHub(`arenarun23/aiedu`) + Vercel(`aiedu`). 앱은 각자 저장소 유지, **빌드 때 가져와 하위 경로로 배치**(앱마다 Vercel 프로젝트를 만들지 않아 한 도메인으로 통일). 따로 배포한 서비스는 `url` 로 연결 가능하게 열어 둠.
3. **화면**: 유아·초등 저학년 느낌(파스텔·둥근 글꼴 Jua/Gowun Dodum·통통 튀는 로고·떠다니는 장식). 카드는 새 창으로 열기.
4. **아이콘**: 웃는 별 캐릭터(분홍 별 + 노랑/복숭아 배경). 파비콘·홈 화면 아이콘 세트.
5. **자동 갱신**: 처음엔 Deploy Hook + 앱 저장소 워크플로. 이후 신뢰성 보강으로 허브에 5분 주기 확인(sync-apps) 추가 → 하지만 **예약 실행이 85분간 안 돌아** 즉시 알림 경로를 주력으로 확인. 새 앱에 Secret 을 안 넣어도 되는 장점을 노려 만들었지만, 예약 실행이 불안정해 결국 "앱 저장소 워크플로 + Secret" 을 표준 절차로 유지.
6. **화면 맞춤**: 태블릿 가로에서 카드가 잘림 → 비례 단위 `--u` 도입. 카드 5개가 되며 4+1 로 어색 → 개수별 열/배율 자동 계산.
7. **word 앱 합류**(5번째): 앱 자체도 화면 맞춤(비례 글자, 가로 2단). 그 사이 `word` 세션에서 올린 기능(음성 보정, "모르겠어" 낱말 추천, 모바일 버튼 확대)과 충돌 → 해결(두 쪽 모두 유지).
8. **game 합류**(6번째, 11-04): 사용자가 만든 `arenarun23/game`(미니게임 6종 모음)을 `apps.json` 에 등록(🎮, peach). 저장소는 처음부터 CLAUDE.md·notify-hub 를 갖추고 있었고 정적·상대경로라 그대로 가져옴. 카드 6개는 가로 3+3 으로 한 화면에 맞음.
9. **복귀 아이콘**(11-04): 6개 서비스에 허브로 돌아가는 웃는 별 아이콘 추가 → 위치를 **페이지 왼쪽 위로 통일**(사용자 지시). 앱 안 🏠 과 겹치지 않게 집 모양 대신 별. 작업 중 사고 2건(충돌 표시 push, 원래 스타일 줄 삭제)을 겪고 `scripts/safe-push.sh` 와 교훈을 문서화.
10. **스킬화**: 이 문서들(aiedu-hub / aiedu-services / add-service)과 `scripts/fit-check.mjs`, `scripts/make-icons.mjs` 로 다른 세션에서 이어받기 가능하게 정리.

## 사용자 선호 (일관되게 드러난 것)
- 한국어 응답, 짧고 명확하게. 결정이 필요한 곳에서만 질문.
- 아이들이 쓰는 기기(삼성 태블릿·폰)에서 **화면이 깨지지 않고 한 화면에 맞는 것**을 매우 중시.
- 수정하면 push → 자동 배포·갱신까지 한 흐름. "반영이 안 된다"는 제보가 오면 코드보다 먼저 **배포본(sha) 비교**.
- Vercel·GitHub 설정 화면 작업은 사용자가 직접 하므로, 메뉴 위치를 구체적으로(주소·버튼 이름) 안내.
