# hangul — 한글 쓰기

- 저장소 `arenarun23/hangul` · 파일: `index.html`(약 33KB 하나), `README.md`. 서버·저장소 없는 정적 페이지. (자체 Vercel 프로젝트 `hangul-xi-jet.vercel.app` 도 따로 존재 — 허브는 쓰지 않음, 사용자가 정리 여부 결정)
- 대상: 유아·초등 1~2학년. 기능: **필기 입력**(캔버스 `#cv`, 손가락/펜) + **음성 입력**(Web Speech API) → 자모 풀이, **따라 쓰기**(`#guide`).
- 화면: 3패널 — 왼쪽(`.panel.left`: 쓰기판 `#pad`+`#cands` 후보, 모드 바 `🧒 유아 / 🎒 1·2학년`, 버튼 ✍️필기·🎤말하기·지우기), 가운데(`.panel.hangul`: 큰 글자 `#big`+그림 `#pic`+읽기 `#reading`+별 `#stars`, ⚙️ 설정: 읽기 속도·목소리·글씨 색·소리 크기), 오른쪽(`#info`: 글자 풀이).
- 필기 인식: 구글 입력도구 비공식 엔드포인트(`itc=ko-t-i0-handwrit&app=hangul`). 최근 수정: **엔진 첫 결과를 그대로 사용**('가'→'가족'으로 바뀌던 문제 해결), **인식 실패 안내가 끝나면 쓴 글씨를 자동으로 지움**(안내 중 새로 쓰면 유지).
- 수정 시 주의: 쓰기판은 터치 이벤트 충돌을 피하려 `touch-action:none`, `user-select:none` 사용. 레이아웃을 바꾼 뒤에는 실제로 필기가 되는지(캔버스 좌표가 어긋나지 않는지) 태블릿 크기에서 확인.
